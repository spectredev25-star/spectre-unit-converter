# 🔄 Unit Converter

> A lightweight command-line unit converter built from scratch with Python.

```text
spectre@engineering-lab:~$ python converter.py
```

## 🧠 About

**Unit Converter** is a terminal-based utility built from scratch with Python for converting values between different units.

The project provides a simple interactive CLI while practicing reusable functions, conditional logic, user input, and mathematical conversions.

This project is part of my **60-Day Python Project Challenge**, where I am building projects from scratch to strengthen my Python, problem-solving, and software engineering skills.
